# 食通グルメマップ

食通の人が実際に推していた店を、地図で眺めるページです。ログイン不要です。

公開URL: https://tamago2022.github.io/shokutsu-map/

- 最初は8,000円以内の店だけ表示します
- ジャンル・予算・都道府県・発信者、メニューの単語で絞り込めます
- ピンを押すと一押しメニュー、発信者、元のツイート、Googleマップへのリンクが出ます
- 「現在地の近く」（だいたい30km以内）も使えます

店の情報は発信者の投稿と、公式・食べログ等で確かめた住所をもとにしています。営業や値段は変わることがあるので、行く前に公式を見てください。
