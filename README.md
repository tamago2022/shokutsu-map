# 食通グルメマップ（試作）

食通のSNS投稿をもとにした、お店の地図です。ピンを押すと、店名・食通の名前・料理メモ・元の投稿・Googleマップへのリンクが出ます。

公開ページ: https://tamago2022.github.io/shokutsu-map/

最初は **8,000円以内** の店だけ表示します。予算・食通・ジャンル・エリアで絞り込めます。

データは2026年11月時点の試作で、河瀬璃菜（りな助）、うどんが主食、ミスター黒猫の公開投稿から拾い、住所と予算は公開情報で補いました。営業や価格は変わることがあるので、行く前に店の最新情報を確認してください。

地図タイルは [OpenStreetMap](https://www.openstreetmap.org/copyright) を使っています。
